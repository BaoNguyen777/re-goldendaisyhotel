# Golden Daisy Hotel — Phu Quoc

Premium tropical hotel website built with Next.js, TypeScript, Tailwind CSS, Framer Motion and Lenis.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

The landing page uses responsive sections for rooms, rooftop pool, dining, wellness, gallery and location. The booking modal links guests to the hotel's Booking.com channel for live rates and availability.

Hotel facts were based on the hotel's official website and current Booking.com listing. Replace the Unsplash image URLs in `app/page.tsx` with the hotel's licensed photography when available.
